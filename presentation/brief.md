## 1. Контекст

**Что это.** Видеозащита итогового проекта по дисциплине «Основы веб-разработки и вёрстки». Студент сверстал одностраничный лендинг вымышленного продукта и рассказывает, как он устроен.

**Как будут смотреть.** Презентация идёт фоном к голосу в записи экрана. Общая длина видео — **до 7 минут**, на слайды отводим около 6,5 минуты. Значит, слайд должен читаться за 2–3 секунды, а подробности звучат голосом. Текста на слайде — минимум, только опорные слова.

**Кто оценивает.** Преподаватель по трём критериям из задания:

1. **Представление проекта** — чёткая, логичная, последовательная подача; решения и инструменты аргументированы.
2. **Дизайн и структура лендинга** — визуальная целостность, понятная структура, все обязательные элементы на месте.
3. **Корректность вёрстки** — оценивается код.

Отсюда главный принцип: **каждое требование задания должно быть видно на слайдах и связано с конкретным местом на сайте.** Матрица соответствия — в разделе 6.

**Язык:** русский. Голос рассказчика — от первого лица, спокойный, без канцелярита и технологического пафоса.

## 2. Формат

- **16:9, 1920 × 1080**, 12 слайдов.
- Текст — живыми текстовыми слоями, не картинкой: автор будет править формулировки.
- Выгрузка: **PDF со встроенными шрифтами и текстовым слоем**. Если инструмент умеет, дополнительно PPTX.
- Шрифты — Google Fonts с кириллицей: **Oswald**, **Inter**, **Marck Script**.
- Анимаций и переходов между слайдами не нужно — запись идёт экраном.

> **Почему 12, а не 10.** Черновик (`draft-deck-v1.pdf` в архиве) был на 10 слайдов, и в нём не хватило места для двух вещей, которые задание требует объяснить прямо: что означает логотип и зачем в форму добавлены поля сверх обязательных. Плюс в черновике не было прохода по обязательным секциям — а это и есть «подтвердить соответствие поставленным задачам». Если нужно строго 10 — объединить слайды 04 + 05 и 10 + 11.

## 3. Продукт — в двух абзацах

**ZenLens** — умные контактные линзы 2062 года. Встроенный прозрачный чип распознаёт объекты в поле зрения и расфокусирует те, что человек занёс в свой стоп-лист: рекламу, вывески, экраны, отдельные лица. На переходе, за рулём и при резком движении фильтр выключается сам.

Слоган первого экрана: *«Настройте свой мир без визуального шума, назойливой рекламы и бывших»*. Три набора: Base — 14 900 ₽, Pro — 24 900 ₽, Ultra — 39 900 ₽. Тон — спокойная ирония: продукт из будущего, который обещает тишину, а не мощность.

## 4. Визуальная система

Презентация должна выглядеть как продолжение сайта: те же цвета, шрифты и приёмы. Сайт — брутализм и ломаная сетка в духе Дэвида Карсона, но собранная аккуратно.

### Цвета

| Роль | HEX | Где |
|---|---|---|
| Фон светлых слайдов | `#F1F0EE` | основной фон |
| Белый | `#FFFFFF` | фон «бумажных» слайдов, карточки |
| Текст и тёмные слайды | `#0D0D0D` | заголовки, тёмный фон |
| Акцент | `#E8100F` | **только** действие, ключевая цифра, метки на полях |
| Второй план | `#77756F` | пояснения, подписи |
| Линии | `#0D0D0D` при 14 % непрозрачности | разделители списков |

Красного мало, и поэтому его замечают. Больше одного-двух красных пятен на слайде — уже перебор.

### Шрифты (размеры для 1920 × 1080)

| Роль | Шрифт | Размер | Детали |
|---|---|---|---|
| Заголовок слайда | Oswald Light 300, ключевое слово — SemiBold 600 | 72–80 px | ВЕРХНИЙ РЕГИСТР, трекинг +4 %, интерлиньяж 0,95 |
| Подзаголовок, крупные цифры | Oswald 500 | 32–48 px | |
| Основной текст | Inter 400 | 22–24 px | интерлиньяж 1,5, цвет `#77756F` |
| Метки и подписи | Oswald 400 | 14–16 px | ВЕРХНИЙ РЕГИСТР, трекинг +30 % |
| Рукописные акценты | Marck Script | 60–150 px | только красным или белым, 1 раз на слайд максимум |
| Код | любой моноширинный (JetBrains Mono, SF Mono, Consolas) | 18–20 px | на чёрной плашке, см. ниже |

### Сквозные элементы каждого слайда

- **Метка раздела** сверху слева: Oswald 14–16 px, верхний регистр, разрядка, серая. Например `ЗАДАЧА`, `ПРОДУКТ`.
- **Номер слайда** снизу справа: `01` … `12`, Oswald, серый.
- **Вертикальная подпись на левом поле** — красная, развёрнута на 90°, читается снизу вверх. Есть не на всех слайдах: указано в раскладке.
- Поля: слева и справа 108 px, сверху 88 px.

### Приёмы, взятые с сайта

- **Чёрная плашка** под наклоном −1,5°, выезжающая из-за левого края (титул).
- **Красная вертикальная лента** с текстом `NO ADS · NO NOISE · NO STRESS` у правого края (титул).
- **Чёрно-белые фотографии.** Цвет — только у той картинки, на которую нужно смотреть прямо сейчас.
- **Жёсткая тень без размытия** со сдвигом 14 px вправо-вниз, `#0D0D0D` при 10 % — для скриншотов и карточек.
- **Лёгкий поворот** одного элемента на слайде (−0,6…−1,5°): «приклеенный» скриншот, штамп. Не больше одного повёрнутого элемента на слайд.
- **Ломаная сетка:** элементы в ряду стоят на разной высоте, заголовок может выступать за колонку текста. Но текст всегда выровнен по левому краю и читается.
- **Фрагменты кода** — чёрная плашка `#0D0D0D`, слева красная полоса 4 px, селекторы красным `#FF5F5E`, комментарии серым `#8F8D87`, остальное `#E7E6E3`.

### Ритм фона

Как на сайте, светлые слайды перемежаются белыми и тёмными:

| Слайды | Фон |
|---|---|
| 01, 02, 03, 05, 06, 08, 10 | светлый `#F1F0EE` |
| 04, 07, 09 | белый `#FFFFFF` |
| 11, 12 | тёмный `#0D0D0D` |

### Чего не делать

- Никаких скруглённых углов — ни у плашек, ни у скриншотов, ни у кнопок.
- Никаких градиентов, неоновых свечений, стоковых иконок, эмодзи, 3D.
- Не добавлять цвета сверх палитры.
- Не центрировать всё подряд: композиция асимметричная, по левому краю.
- Не перегружать: если текст не влезает в кегль 22 px — сокращать, а не уменьшать кегль.
- Не перерисовывать интерфейс сайта: использовать настоящие скриншоты из архива.

### 10 — Flexbox и позиционирование · 0:40

**Задача слайда:** показать код, который закрывает два технических требования.

**Метка:** `ВЁРСТКА` · **Вертикальная подпись:** `FLEX · POSITION`

**Заголовок:** ВСЁ НА **FLEX**, СЛОИ — НА **POSITION**

**Левая колонка — Flexbox.** Текст: *Ни float, ни grid: каждая раскладка на странице — flex-контейнер. Лесенка карточек — обычный margin.* Код:

```css
.cards {
  display: flex;
  flex-wrap: wrap;
  align-items: flex-start;
  gap: 28px;
}

/* карточки стоят на разной высоте */
.kit      { flex: 1 1 300px; }
.kit-dark { flex: 1.15 1 320px; margin-top: 54px; }
.kit-up   { margin-top: 24px; }
```

**Правая колонка — позиционирование.** Четыре строки, метка слева красным моноширинным:

| | Что | Зачем |
|---|---|---|
| `fixed` | шапка, кнопка «наверх» | не уезжают при прокрутке |
| `sticky` | колонка «Как работает» | заголовок держится, пока листаются шаги |
| `absolute` | линза, *revolution*, реплики, бейджи, номера | слои поверх фото |
| `relative` | секции и карточки | точки отсчёта для слоёв |

Под таблицей — короткий код:

```css
.header    { position: fixed; top: 0; left: 0; }
.tech-side { position: sticky; top: calc(var(--head) + 32px); }
.hero-lens { position: absolute; left: 50%; top: 50%;
             transform: translate(-50%, -50%); }
```

**Голос:**
> Вся раскладка на Flexbox — без float и grid. Лесенку карточек я сделал обычным отступом сверху, на узких экранах он обнуляется. Позиционирование — четыре способа под четыре задачи: fixed для шапки, sticky для колонки, которая держится при прокрутке, absolute для слоёв поверх фотографий и relative для точек отсчёта.

**Заголовок:** НИЧЕГО НЕ ПРЫГАЕТ **БЕЗ ПРИЧИНЫ**

**Левая половина — движение.** Список с тире:

- **transform** — карточка приподнимается, фото увеличивается, логотип и выбранный штамп поворачиваются
- **filter** — чёрно-белое фото становится цветным

Код:

```css
.kit {
  transition: transform .4s, box-shadow .4s, border-color .4s;
}
.kit:hover {
  transform: translateY(-10px);
  border-color: var(--ink);
  box-shadow: 14px 14px 0 rgba(13, 13, 13, .1);
}
.kit:hover .kit-photo img {
  filter: none;
  transform: scale(1.07) rotate(.6deg);
}
```

**Правая половина — адаптив.** Три скриншота первого экрана рядом, выровнены по нижнему краю, подписи под ними `1440` · `820` · `390`:

**Голос:**
